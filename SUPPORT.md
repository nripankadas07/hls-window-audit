# Support, contribution and security

Report reproducible bugs with Python/SQLite version, expected and actual results, command and a minimal synthetic fixture through this repository's Issues. No response-time guarantee. Do not post private mail, databases, playlists, credentials or personal images.

Contributions: use a descriptive branch, preserve documented unsupported cases and include a user-facing regression. Run python verify.py. Keep runtime dependencies zero and do not weaken validation to hide failures.

Security: do not post secrets or exploit details publicly. Use GitHub private vulnerability reporting if enabled; otherwise request a private contact in a minimal issue containing no sensitive details. Run untrusted inputs with deployment-appropriate OS resource controls. This MVP is not a security certification.
